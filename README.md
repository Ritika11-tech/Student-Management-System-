# Student Management System

## Description

A simple menu-driven Python program used to manage student records.

Each record contains:

* Student ID
* Name
* Age
* Course
* Marks

## Features

* Add a student
* View all students
* Search student by ID or Name
* Update student details
* Delete a student
* Exit the program

## Concepts Used

* Lists
* Dictionaries
* Functions
* Loops
* Conditional Statements
* User Input
